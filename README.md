# 게시판모아(BoardMoa) 앱 연동 모듈 (appapi)

스마트폰 게시판 앱 **게시판모아**가 XE 1.11 이상·Rhymix 2.1 이상 사이트의 게시판을 읽고 쓸 수 있게 하는 모듈입니다.

- 앱 받기: [iPhone·iPad (App Store)](https://apps.apple.com/kr/app/id6826114071) · [Android (Google Play)](https://play.google.com/store/apps/details?id=com.easyapplabs.boardmoa)
- 최신 버전: [latest.json](latest.json) · 내려받기: [releases/](releases/)
- 설치 안내: [INSTALL.md](INSTALL.md)
- 처음 한 번 설치한 뒤에는 관리자 화면 → 앱 연동 → **업데이트 확인**으로 새 버전을 받을 수 있습니다. 받은 파일은 전자서명을 확인한 뒤에만 설치됩니다.
- 모듈을 설치해 앱에서 잘 열리면 easyapplabs@gmail.com 으로 알려 주세요. 앱의 추천 사이트에 올려 드립니다.
